⚙ Privacidade e dados

Este aplicativo funciona sem servidor. Campanhas e senha são armazenadas localmente no navegador. Não existe sincronização entre dispositivos.

Para compartilhar com outra pessoa, envie este HTML. Ela configura a própria senha e começa com o próprio banco de dados vazio. A senha local não impede que alguém com acesso técnico ao arquivo ou ao navegador leia os dados. Para contas compartilhadas com proteção real, é necessário um servidor com autenticação.
